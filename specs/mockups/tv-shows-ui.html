Design tokens & rationale

--kind-show: #0EA5E9 · teal
--kind-movie: #F59E0B · amber
--kind-show-tint
--kind-movie-tint

Icons — Lucide-style stroke icons: tv for shows, film for movies. Every colored surface (chip, row border, segmented button) is paired with an icon and text label, so color is never the sole cue (WCAG 1.4.1).

Why segmented vs tabs? Tabs suggest peer views of the same data; a segmented toggle communicates a content-type filter that cascades through every downstream view (Queue, This or That, Combined, History). One selection, global scope — matches the mental model users already have from Netflix / Plex.

Reserved space — the dashed S · E pill in each show row is a placeholder for the forthcoming episode-progress chip (e.g. S2E4). Layout is stable today so shipping progress later won't reflow rows.
